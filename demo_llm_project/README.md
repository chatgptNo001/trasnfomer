# LLM 训练流程演示（面向初学者）

本演示工程用 **Python 伪代码** 展示一个完整的 LLM 训练流程，帮助初学者回答四个核心认知问题：

1. **学习目标**：模型训练要达成什么样的学习成果？
2. **学习过程**：模型如何具体进行学习和训练？
3. **知识存储与内化**：模型把知识“存到哪里”？
4. **泛化能力与局限性**：如何举一反三？幻觉怎么产生，用户如何应对？

> 说明：代码刻意保持“可读性优先”，用伪代码和注释解释关键概念，**不追求可执行**。

## 四个核心认知问题的回答（简化版）

### 1. 学习目标：模型要学到什么？

**目标是：给定上下文，最大化预测下一个词/Token 的概率。**

简化目标（语言建模）：

```
最大化  P(x_t | x_<t)
等价于最小化  L = -Σ log P(x_t | x_<t)
```

这意味着模型训练的核心成果是：**能从统计规律中学会“在上下文中接下一个词”。**

### 2. 学习过程：模型如何训练？

1. 数据预处理：文本 → Token ID → 批次 (batch)
2. 前向计算：输入 Token → 嵌入 → 注意力 → 输出 logits
3. 计算损失：
   - 交叉熵损失：
     `L = -Σ y * log(p)`
4. 反向传播：计算梯度 `∂L/∂θ`
5. 参数更新：
   - `θ = θ - lr * ∇θ L`

### 3. 知识存储与内化：知识存在哪里？

**知识存储在模型参数中（权重矩阵）。**
- 参数就是模型“记忆”的载体
- 训练时的每一次梯度更新都在改变这份记忆

### 4. 泛化能力与局限性：举一反三 & 幻觉

- **泛化**：模型通过大量样本学习“模式”，在新场景中复用已学到的模式
- **局限性**：训练数据不足或偏差 → 模型容易产生幻觉或错误推断
- **应对方式**：
  - 使用可靠检索与事实核验
  - 减少开放式“猜测”问题
  - 限制温度与采样策略
