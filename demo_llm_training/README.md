# LLM 训练流程演示工程（面向初学者）

本工程用 **Python 伪代码** 演示一个“从数据到推理”的完整训练流程，重点回答小白用户最关心的四个核心认知问题：

1. **学习目标**：模型要优化的目标与最终学习成果是什么？
2. **学习过程**：模型如何通过数据和损失函数进行训练？
3. **知识存储与内化**：模型如何把知识“存”到参数里？
4. **泛化能力与局限性**：模型如何举一反三、为何会产生幻觉、用户该如何应对？

> 说明：本工程代码为“可运行风格的伪代码”，强调概念与流程清晰，不追求可执行性。

## 工程结构

```
 demo_llm_training/
 ├─ README.md                # 本说明
 ├─ data/
 │  └─ sample_corpus.txt      # 简易训练语料（示例）
 ├─ docs/
 │  └─ core_questions.md      # 四个核心问题的直观解释
 └─ src/
    └─ llm_training_demo.py   # 训练流程伪代码（包含公式与日志）
```

## 如何阅读

1. 先阅读 `docs/core_questions.md`，理解学习目标、过程、知识内化与泛化局限。
2. 进入 `src/llm_training_demo.py`，逐段阅读注释与公式，结合日志输出理解训练流程。
3. 查看 `data/sample_corpus.txt`，理解“语料 -> 训练样本”如何形成。

## 你能学到什么

- LLM 的训练目标与损失函数的直观含义
- 训练循环中“前向-损失-反向-更新”的基本机制
- “知识”如何通过参数更新被内化
- 泛化为何可能成功、也为何会出现幻觉
