# LLM 训练流程演示（面向初学者）

本示例通过**Python 伪代码**演示一个极简的 LLM 训练流程，帮助回答四个核心问题：

1. **学习目标**：模型训练的目标是什么？
2. **学习过程**：模型是如何进行学习和训练的？
3. **知识存储与内化**：模型把知识存到哪里？如何“内化”？
4. **泛化能力与局限性**：模型如何举一反三？幻觉从何而来？如何应对？

> 注意：该项目是可读性优先的“教学演示工程”。为了清晰解释概念，模型结构被极度简化。

## 1. 学习目标（训练目标）

**核心目标：预测下一个词（Next Token Prediction）。**

- 给定输入 token `x`，模型输出概率分布 `p(y|x)`，希望预测到正确的下一个词 `y`。
- 损失函数使用交叉熵：

\[
\mathcal{L} = -\log p_{target}
\]

训练就是让损失函数尽可能小，意味着模型能更准确地预测下一个词。

---

## 2. 学习过程（训练循环）

训练过程包括四步：

1. **前向传播**：输入 token -> 输出 logits -> softmax 得到概率
2. **计算损失**：交叉熵衡量预测错误程度
3. **反向传播**：计算梯度
4. **参数更新**：梯度下降更新模型权重

公式如下：

\[
\nabla W = p - y_{onehot}
\]

\[
W = W - \eta \cdot \nabla W
\]

其中 `η` 是学习率（learning rate）。

---

## 3. 知识存储与内化

在训练中，**模型的知识存储在参数矩阵 W 中**。

- 每次更新参数，就是把“新的经验”写入权重。
- 参数更新越充分，模型越能记住训练数据的统计规律。
- 这就是“知识内化”的过程。

---

## 4. 泛化能力与局限性（幻觉机制）

### 泛化能力

模型通过学习大量数据中的模式，在类似场景中能做出合理预测。
例如：训练数据中频繁出现“我 喜欢 学习”，模型就会在输入“我”时更倾向输出“喜欢”。

### 幻觉问题

当输入超出训练分布（OOV 或冷门组合）时，模型仍会输出“最可能”的词——
但这些输出可能不真实或不可靠，这就是**幻觉**。

**应对建议：**
- 使用检索增强（RAG）来提供外部事实依据
- 做模型输出校验（如规则或事实核验）
- 提示用户结果可能不确定
