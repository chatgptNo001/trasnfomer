# LLM 训练流程演示（面向初学者）

本演示工程用 **Python 伪代码** 展示一个最小化的 LLM 训练流程：

- **学习目标**：通过“下一词预测”学习语言规律。
- **学习过程**：数据预处理 → 模型前向 → 计算损失 → 反向传播 → 参数更新。
- **知识存储与内化**：知识体现在参数（权重）中，通过梯度更新内化。
- **泛化与局限**：泛化来自统计模式的组合与抽象，但也可能产生“幻觉”。

## 目录结构

```
./demo_llm_training
├── data
│   └── sample_corpus.txt     # 迷你语料
├── src
│   ├── tokenizer.py          # 简易分词器与编码
│   ├── model.py              # 伪代码模型结构
│   ├── train_demo.py          # 训练循环与日志/可视化
│   └── utils.py              # 公共函数
└── README.md
```

## 如何阅读

1. 先看 `src/train_demo.py`，了解完整训练流程。
2. 再看 `src/model.py` 理解“模型结构”。
3. 看 `src/tokenizer.py` 和 `src/utils.py` 了解数据处理与数学公式。

> 这是概念演示工程，重点是流程与概念，不追求可直接用于生产训练。
