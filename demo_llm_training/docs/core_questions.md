# 四个核心认知问题（面向小白）

## 1) 学习目标：模型的训练目标是什么？

**核心目标**：让模型学会“给定上下文，预测下一个最合理的词”。

- 用概率语言表述：最大化真实文本序列的似然。
- 用损失函数表述：最小化预测分布与真实分布之间的差异（常用交叉熵）。

直观理解：模型就像在做“填空题”，越填越准。

## 2) 学习过程：模型如何学习？

训练过程可以概括为四步循环：

1. **前向传播**：输入上下文，得到预测结果。
2. **计算损失**：用公式衡量“预测错了多少”。
3. **反向传播**：把误差信号传回去，计算梯度。
4. **参数更新**：沿着梯度下降，调整参数。

这就像“不断试错并纠正”，直到预测越来越准确。

## 3) 知识存储与内化：模型如何记住知识？

模型的“知识”并不是存成数据库，而是**分散地编码在大量参数里**。

- 参数更新 = 记忆写入
- 多次训练 = 逐步巩固

因此，知识是“隐式的”：你看不到它写在哪里，但它会影响模型输出。

## 4) 泛化能力与局限性：模型为什么会举一反三、也会幻觉？

**泛化的来源**：模型学到的是“统计规律”而不是死记硬背。

**局限和幻觉的原因**：

- 数据中缺乏某些真实模式，模型只能“猜”。
- 训练目标是“预测合理的词”，不是“保证事实正确”。
- 复杂问题超出训练分布时，模型会出现不可靠推断。

**用户应对建议**：

- 对关键信息做二次验证。
- 用明确上下文限制模型范围。
- 识别“看似合理但无出处”的回答。
